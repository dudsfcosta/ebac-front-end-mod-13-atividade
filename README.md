# 🎓 EBAC — Atividade do Módulo 13: Agência Criativa Web

## 📖 Sobre

Site institucional completo, aplicando na prática a organização de estilos em SASS aprendida no módulo.

## 🚀 Como visualizar

Abra o `index.html` no navegador (o CSS já está compilado em `css/`).

## 🛠️ Tecnologias

HTML5 • SASS/SCSS

## 💡 O que aprendi

- Aplicação de SASS em um projeto real de várias seções
- Manutenção de estilos a partir de variáveis e mixins
